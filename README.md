# PESTPULSE — GitHub Pages Website

Website statis responsif untuk konsep **PESTPULSE: Smart Pest Trap**. Dibangun dengan HTML, CSS, dan JavaScript murni; tidak memerlukan build tools.

## Isi
- `index.html` — struktur dan konten website
- `style.css` — desain responsif
- `script.js` — menu mobile, tab prototype, simulator sensor, dan draft email kolaborasi

## Deploy ke GitHub Pages
1. Buat repository baru di GitHub.
2. Upload ketiga file (`index.html`, `style.css`, `script.js`) ke root repository.
3. Buka **Settings → Pages**.
4. Pada **Build and deployment**, pilih **Deploy from a branch**.
5. Pilih branch `main`, folder `/(root)`, lalu **Save**.
6. Tunggu deployment dan buka URL GitHub Pages yang diberikan.

## Catatan akurasi
Antarmuka dan data dalam prototype bersifat ilustratif. Tidak ada perangkat IoT yang terhubung langsung, model AI yang dijalankan, atau hasil pengujian lapangan. Klaim akurasi, selektivitas perangkap, serta dampak pengurangan pestisida perlu divalidasi sebelum digunakan sebagai klaim kinerja.
